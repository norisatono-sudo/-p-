# うp主エピソード生成ツール

テーマとキーワードを入力すると、参考にしたSNS投稿やブログ記事をもとに「うp主が～」に続くリアルな体験談風セリフを3パターン提案するWebアプリです。

## 使い方

1. `index.html` をブラウザで開く
2. **テーマ**（動画の主題）と**キーワード**を入力
3. **参考ソース**にSNS投稿やブログ記事のテキストとURLを貼り付け
4. 「セリフを生成する」をクリック

## 生成モード

- **テンプレート生成（APIキー不要）**: すぐに使える。参考ソースの引用を含むセリフをテンプレートベースで生成
- **AI生成（APIキー使用）**: OpenAI / Anthropic APIでより自然なセリフを生成

## 生成されるセリフの種類

| パターン | 例 |
|---|---|
| 実体験型 | 「うp主もよくこの道は使うんだが、八王子JCTはしょっちゅう混んでいる印象だ」 |
| 伝聞型 | 「うp主がかつて聞いた話なんだが、友人が川沿いの道で速度取り締まりに遭ったらしい」 |
| 共感・あるある型 | 「うp主的にはこれ完全にあるあるでさ…」 |

## 共有方法

`index.html` を1ファイル渡すだけで誰でも使用可能。サーバー不要。
