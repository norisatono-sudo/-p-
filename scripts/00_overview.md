# ワイン教育ショート動画シリーズ 企画概要

## コンセプト

**「ワインって難しそう」を「なんだ、そういうことか」に変える**

ターゲット：ワインに興味はあるけど難しく感じている20〜40代。
飲み会やレストランでワインを選ぶ場面で困ったことがある人。

---

## シリーズ構成（全7本）

| # | タイトル | キーメッセージ |
|---|----------|--------------|
| 01 | ワインって結局、何種類あるの？ | 5種類を覚えれば選べる |
| 02 | タンニンって何？渋みの正体 | 渋みの仕組みがわかれば怖くない |
| 03 | ワインのラベル、どこ見ればいい？ | 3つのポイントだけ見る |
| 04 | ワインと料理、何を合わせればいいの？ | 色を合わせるだけでOK |
| 05 | ワインの温度、なんで大事なの？ | 温度で味が変わる |
| 06 | ワイングラスの持ち方、どれが正しい？ | 場に合わせれば正解はない |
| 07 | 開けたワイン、どうやって保存する？ | 冷蔵庫で数日持つ |

---

## 動画構成（各60秒）

```
0〜5秒   : フック（問いかけ or 意外な事実）
5〜45秒  : メイン解説（3〜4ポイント）
45〜60秒 : まとめ + 次回予告 / CTA
```

---

## 演出・撮影メモ

- **口調：** タメ語ベース。親しみやすく、説教臭くない
- **テロップ：** 重要ワードを大きく・太く表示
- **BGM：** おしゃれすぎず、軽快なアコースティック系
- **小道具：** 実際のワインボトル・グラスを使う（リアリティを出す）
- **画角：** ボトルのアップ、グラスへの注ぎ、ラベルのクローズアップを活用
